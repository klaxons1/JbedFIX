# Recovered Jbed VM sources

Эта директория предназначена **только для исходников, восстановленных из
`lib/armeabi/libjbedvm.so`**, которые можно будет отдельно собирать и
проверять. Исходники Android-приложения, JNI-совместимости и диагностические
патчи сюда не помещаются.

Структура:

```text
vm_recovered/
  include/   восстановленные типы, структуры и публичные внутренние API VM
  src/       восстановленные C/C++-исходники VM и AOT/FastBCC backend-а
```

`docs/libjbedvm.so.c` остаётся исходной Hex-Rays-декомпиляцией и не считается
рекомпилируемым исходником: в `vm_recovered/src` будут попадать только
нормализованные файлы с исправленными типами, прототипами и зависимостями.

Каждый восстановленный модуль должен содержать в начале:

- диапазон адресов оригинального ARM ELF;
- уровень уверенности reverse engineering;
- соответствие исходным `sub_...`-функциям или ROM metadata;
- способ отдельной компиляции/тестирования.

На данный момент директория создана как отдельный target для дальнейшего
восстановления самой VM; полноценный исходный код AOT-компилятора ещё не
заявляется готовым.
